= NetApp Backup and RecoveryにおけるVMwareワークロードの既知の制限事項
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Backup and RecoveryをVMwareワークロードに使用する前に、これらの制限事項を確認してください。

NetApp Backup and Recovery では、VMwareワークロードに対して以下の操作はサポートされていません。

* NetApp Console ローカル展開のバックアップとリカバリのプレビューリリースでは、オブジェクトストレージへのバックアップは ONTAP S3 と StorageGRID の宛先のみサポートされています。バックアップのアーカイブは、このプレビューリリースではサポートされていません。
* vVol サポート
* メール統合
* ロールベースアクセス制御（RBAC）のサポート

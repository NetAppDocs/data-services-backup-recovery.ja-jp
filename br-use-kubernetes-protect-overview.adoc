= NetApp Backup and Recoveryを使用したKubernetes保護のワークフロー
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Backup and Recovery を使用して、単一のインターフェースから Kubernetes クラスターとアプリケーションの検出、管理、保護を行うことができます。

次の図は、Kubernetesのバックアップとリカバリの構成要素と基本アーキテクチャ、およびデータのコピーを異なる場所に保存する方法を示しています。

image:../media/backup-recovery-architecture-diagram.png["Kubernetes ワークロードのバックアップとリカバリのアーキテクチャ図"]

NetApp Backup and Recovery は、 Kubernetes ワークロードの管理に次の利点をもたらします。

* コンテナや仮想マシンを含む、複数のKubernetesクラスタにわたるアプリケーションを保護するための単一のコントロールプレーン。
* NetApp SnapMirrorとのネイティブ統合により、バックアップおよびリカバリのワークフローにおけるストレージのオフロードが可能になります。
* Kubernetes アプリケーションの永久増分バックアップにより、復旧ポイント目標 (RPO) と復旧時間目標 (RTO) が低下します。

* link:br-use-manage-kubernetes-clusters.html["NetApp Backup and Recovery で Kubernetes クラスターを管理する"]。
* link:br-use-protect-kubernetes-applications.html["Kubernetes アプリケーションを追加して NetApp Backup and Recovery で保護する"]。
* link:br-use-manage-kubernetes-applications.html["NetApp Backup and RecoveryでKubernetesアプリケーションを管理する"]。

= Oracle データベース ワークロードの NetApp Backup and Recovery に関する既知の制限事項
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Backup and RecoveryにおけるOracle Databaseワークロードの現在の制限事項とサポートされていないアクションを確認してください。

以下の操作は、NetApp Backup and Recovery のプレビューリリースにおける Oracle Database ワークロードではサポートされていません：

* データベースを特定のポイントインタイムまたはSCNに復元して不完全なリカバリを実行した後、後でそのリカバリより前のポイントに復元する必要がある場合は、復元先の設定で「制御ファイル」も選択する必要があります。制御ファイルを復元しない場合、データベースは前回の不完全なリカバリより前のポイントインタイムに復元することができません。
* NetApp Console ローカル展開のバックアップとリカバリのプレビューリリースでは、オブジェクトストレージへのバックアップは ONTAP S3 と StorageGRID の宛先のみサポートされています。バックアップのアーカイブは、このプレビューリリースではサポートされていません。

= NetApp Backup and Recovery IAM ロール
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
IDおよびアクセス管理（IAM）を使用して、各ユーザーがアクセスできるNetApp Backup and Recoveryの機能と操作を制御します。

NetApp Backup and Recovery に固有の IAM ロールについては、 https://docs.netapp.com/us-en/console-setup-admin/reference-iam-backup-rec-roles.html["NetApp ConsoleのNetApp Backup and Recoveryの役割"^]を参照してください。

[role="lead"]
NetApp Backup and RecoveryにおけるKubernetesワークロードの現在の制限と回避策を確認します。



[[limitation-in-the-backup-and-recovery-preview-for-netapp-console-local-deployment]]
== NetApp Console ローカル展開のバックアップとリカバリプレビューにおける制限事項

NetApp Console ローカル展開のバックアップとリカバリのプレビューリリースでは、オブジェクトストレージへのバックアップは ONTAP S3 と StorageGRID の宛先のみサポートされています。バックアップのアーカイブは、このプレビューリリースではサポートされていません。



[[changing-the-protection-policy-for-an-application]]
== アプリケーションの保護ポリシーの変更

アプリケーションの保護ポリシーを変更して別のバケットまたはセカンダリ レプリケーションターゲットを使用するようにした場合、保護が失敗する可能性があります。

*回避策*：アプリケーションを削除して、再度追加してください。



[[3-2-1-protection-policy-configuration-limitation]]
== 3-2-1保護ポリシー設定の制限

オブジェクトストレージのバックアップをセカンダリ システムへのレプリケーションとは別にスケジュールする 3-2-1 保護ポリシーを作成すると、保護機能が停止する可能性があります。

*回避策*：アプリケーションを削除して再度追加し、別の保護ポリシーで保護してください。

[role="lead"]
NetApp Backup and Recoveryがワークロード全体のバックアップおよびリストア処理でサポートするソース システム、セカンダリ システム、およびオブジェクト ストレージの保存先を確認します。



[[supported-systems-for-backup-and-restore-operations]]
== バックアップおよび復元操作でサポートされているシステム

NetApp Backup and Recovery は、 ONTAPシステムとパブリックおよびプライベート クラウド プロバイダーをサポートします。



[[supported-regions]]
=== サポートされている地域

NetApp Backup and Recovery は、多くの Amazon Web Services、Microsoft Azure、Google Cloud リージョンでCloud Volumes ONTAPによってサポートされています。

https://bluexp.netapp.com/cloud-volumes-global-regions["グローバル地域マップを使用して詳細を確認する"^]



[[supported-backup-destinations]]
=== サポートされているバックアップ先

NOTE: Wasabiは、現時点で唯一の認定されたS3互換オブジェクトストレージプロバイダです。その他のS3互換プロバイダは検証されていません。

[[supported-restore-destinations]]
=== サポートされている復元先

セカンダリ システム（複製ボリューム）またはオブジェクト ストレージ（バックアップ ファイル）に存在するバックアップ ファイル、仮想マシン、データベース、または Kubernetes リソースから、以下のシステムにデータを復元できます。スナップショットはソース システムに存在し、その同じシステムにのみ復元できます。


NOTE: Wasabiは、現時点で唯一の認定されたS3互換オブジェクトストレージプロバイダです。その他のS3互換プロバイダは検証されていません。

復元にあたっては、以下の点に留意してください：

* Cloud Volumes ONTAP（レプリケーション）からのリストアは、Cloud Volumes ONTAPにのみ実行できます。ただし、AWSのCloud Volumes ONTAPは、Amazon FSx for NetApp ONTAPへのリストアもサポートしています。
* オンプレミスONTAP（レプリケーション）からのリストアは、オンプレミスONTAPにのみ実行できます。
* ファーストパーティのAmazon FSx for NetApp ONTAPおよびGoogle Cloud NetApp Volumesからの復元（レプリケーション）は、それぞれのファーストパーティ システムにのみ実行できます。
* Amazon S3からAmazon FSx for NetApp ONTAPへのリストアは、次の順序に従う必要があります：Amazon S3からCloud Volumes ONTAPへ、次にCloud Volumes ONTAPからAmazon FSx for NetApp ONTAPへ。



NOTE: 「オンプレミス ONTAPシステム」とは、FAS、AFF、およびONTAP Selectシステムを指します。

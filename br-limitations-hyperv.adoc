[role="lead"]
Hyper-Vワークロードに関する現在の制限事項とサポートされていないアクションを NetApp Backup and Recovery で確認してください。



[[unsupported-actions]]
== サポートされていないアクション

Hyper-V ワークロードに対して、NetApp Backup and Recovery ではサポートされていない操作は次のとおりです：

* NetApp Console ローカル展開のバックアップとリカバリのプレビューリリースでは、オブジェクトストレージへのバックアップは ONTAP S3 と StorageGRID の宛先のみサポートされています。バックアップのアーカイブは、このプレビューリリースではサポートされていません。
* Microsoft Windows Server 2025 を使用している場合、SANストレージに保存されている第2世代VMの保護はサポートされていません。
* 複数のHyper-VホストのVMを使用してリソースグループを作成する
* 複数のCIFS共有にまたがるスパンニングディスクの使用
* Hyper-Vの「プロセッサ互換性」設定に関わらず、異なるCPUベンダー（IntelからAMD、またはその逆）のシステム間でVMまたはVMデータを復元することはできません。この設定は、同一ベンダーの異なる世代間（例：IntelからIntel、AMDからAMD）の互換性のみをサポートします。

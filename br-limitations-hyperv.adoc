= Hyper-V ワークロード向けNetApp Backup and Recoveryの既知の制限
:hardbreaks:

:nofooter:

[role="lead"]
Hyper-Vワークロードに関する現在の制限事項とサポートされていないアクションを NetApp Backup and Recovery で確認してください。



[[unsupported-actions]]
== サポートされていないアクション

NetApp Backup and Recoveryでは、Hyper-Vワークロードに対して以下の操作はサポートされていません：

* NetApp Console ローカル展開のバックアップとリカバリのプレビューリリースでは、オブジェクトストレージへのバックアップは ONTAP S3 と StorageGRID の宛先のみサポートされています。バックアップのアーカイブは、このプレビューリリースではサポートされていません。
* NetApp Backup and Recoveryは現在、FlexGroupボリュームでホストされているHyper-V LUNの保護をサポートしていません。
* 複数のHyper-Vホスト上の仮想マシンを使用してリソースグループを作成することはできません。
* Hyper-V の「プロセッサ互換性」設定に関係なく、異なる CPU ベンダー（Intel から AMD またはその逆）のシステム間で VM または VM データをリストアすることはできません。この設定は、同じベンダーの異なる世代（たとえば、Intel から Intel、または AMD から AMD）間の互換性のみをサポートします。

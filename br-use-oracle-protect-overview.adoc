= Oracle DatabaseワークロードをNetApp Backup and Recoveryで保護する
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Backup and Recovery を使用して、高速でスペース効率に優れた、「crash consistent state（障害など予期しないシャットダウン時と同様）」の状態、およびデータベースと整合性のあるバックアップとリストアにより、Oracle Database のワークロードとログを保護します。ワークロードを AWS S3、StorageGRID、Azure Blob、または ONTAP S3 にバックアップし、オンプレミスの Oracle ホストにバックアップをリストアできます。

NetApp Backup and Recoveryを使用して3-2-1保護戦略を実装します。この戦略では、ソースデータの3つのコピーを2つの異なるストレージシステムに保存し、さらに1つのコピーをクラウドに保存します。3-2-1方式の利点は次のとおりです：

* 複数のデータ コピーにより、内部および外部のサイバー セキュリティの脅威から保護されます。
* 異なる種類のメディアを使用することで、ある種類のメディアが故障した場合でも復旧が可能になります。
* オンサイト コピーから迅速に復元し、オンサイト コピーが侵害された場合はオフサイト コピーを使用できます。




[[oracle-data-guard-support]]
== Oracle Data Guardのサポート

NetApp Backup and Recoveryは、単一インスタンスのプライマリデータベースと、マウント状態の物理スタンバイデータベースが1つ存在するOracle Data Guard構成を保護できます。

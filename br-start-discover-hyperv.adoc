= NetApp Backup and RecoveryでHyper-Vワークロードを検出して管理する
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Backup and Recovery で Hyper-V 仮想マシンを検出し、保護ポリシーを使用して保護できるようにします。

*必須 NetApp コンソールロール* バックアップおよびリカバリのスーパー管理者。link:reference-roles.html["バックアップとリカバリの役割と権限"] について学ぶ。 https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["すべてのサービスに対するNetApp Consoleのアクセスロールについて学習します"^]。



[[add-a-hyper-v-host-and-discover-resources]]
== Hyper-Vホストを追加してリソースを検出する

Hyper-V ホスト情報を追加して、NetApp Backup and Recovery が仮想マシンを検出できるようにします。各コンソールエージェント内で、リソースを検出するシステムを選択します。


NOTE: ストレージシステムを NetApp Console に追加した後、リソースを検出するまで数分お待ちください。ストレージシステムを追加した直後にリソースを検出すると、検出が失敗する可能性があります。


NOTE: Hyper-V ホストを追加してリソースを検出すると、 NetApp Backup and Recoveryによって、仮想マシンの管理と保護を支援するために、Hyper-V ホストにNetApp Hyper-V プラグインとNetApp SnapCenter Windows FileSystem プラグインがインストールされます。

.手順
. NetApp Console メニューから、*Protection* > *Backup and Recovery* を選択します。
. *リソースの検出*を選択します。
. 次の情報を入力してください。
+
.. *ワークロードの種類*: *Hyper-V* を選択します。
.. *Hyper-V の設定*：次の手順を実行してください。
+
... この Hyper-V ホストの資格情報をまだ保存していない場合は、[資格情報の追加] を選択します。
+
**** このホストで使用するコンソール エージェントを選択します。
**** この資格情報の名前を入力します。
**** アカウントのユーザー名とパスワードを入力します。
**** *完了*を選択します。


... ホストのFQDNまたはIPアドレスを入力し、コンソールエージェントと資格情報を選択して、新しいHyper-Vホストを追加します。コンソールエージェントがFQDNを解決できない場合は、代わりにIPアドレスを使用してください。フェイルオーバークラスタの場合は、クラスタ管理IPアドレスを入力してください。


.. *詳細設定*：必要に応じて、NetApp Hyper-V プラグインのインストールパスを入力します。


. *Discover*を選択します。
+

TIP: このプロセスには数分かかる場合があります。



.結果
NetApp Backup and Recovery がリソースを検出すると、インベントリ ページのワークロード リストに Hyper-V ワークロードが表示されます。



[[refresh-a-hyper-v-host]]
== Hyper-Vホストを更新する

Hyper-Vホストをリフレッシュして、ホスト上のVMsのリストを更新し、接続されているストレージをマッピングします。MetroClusterのスイッチオーバーまたはスイッチバックのあと、あるいは最近ホストでVMsを追加または削除した場合は、この操作が必要になることがあります。


IMPORTANT: Hyper-VホストがNetApp MetroCluster構成で保護されている場合は、MetroClusterのスイッチオーバーまたはスイッチバックのあと、次回のスケジュールされたバックアップや手動バックアップ、またはスナップショットの前に、ホストを更新してください。ホストが更新される前にそのホストに対して実行されたバックアップやスナップショットはすべて失敗します。ホストを手動で更新しない場合、Backup and Recoveryは12時間以内に自動的にホストを更新します。

.手順
. NetApp Console メニューから、*Protection* > *Backup and Recovery* を選択します。
. Hyper-Vワークロードタイルを選択します。
. NetApp Backup and Recoveryメニューから、*インベントリ* を選択します。
. Hyper-Vワークロードタイプの*表示*リンクを選択します。
. 更新するHyper-Vホストを選択し、「アクション」アイコン image:../media/icon-action.png["アクションオプション"] > *更新* を選択します。




[[continue-to-the-netapp-backup-and-recovery-dashboard]]
== NetApp Backup and Recoveryダッシュボードに進みます

.手順
. NetApp Console メニューから、*Protection* > *Backup and Recovery* を選択します。
. Hyper-Vワークロードタイルを選択します。
. 「バックアップとリカバリ」メニューから、「ダッシュボード」を選択します。
. データ保護の健全性を確認します。新たに検出、保護、バックアップされたワークロードに基づいて、リスクにさらされているワークロードまたは保護されているワークロードの数が増加します。
